# Personal Portfolio — ramsurya.me

A responsive, performant personal portfolio built with **React.js** and **Tailwind CSS**, deployed on a custom domain with a CI/CD pipeline.

## 🔗 Live Demo
👉 [ramsurya.me](https://www.ramsurya.me)

## ✨ Features
- Built with React.js + Tailwind CSS for a modern, component-driven UI
- Deployed on custom domain with Git-based CI/CD workflow
- Optimised for performance, SEO, and web accessibility (WCAG)
- Mobile-first responsive design across all breakpoints
- Integrated blogs, photos, and embedded audio content

## 🛠️ Tech Stack
- **Framework:** React.js
- **Styling:** Tailwind CSS
- **Runtime:** Node.js
- **Version Control:** Git & GitHub
- **Deployment:** CI/CD pipeline on custom domain

## 📁 Project Structure
```
src/
├── components/    # Reusable React components
├── pages/         # Page-level components
├── assets/        # Images, audio, static files
└── styles/        # Global styles
```

## 🚀 Getting Started
```bash
git clone https://github.com/Ramsurya-M/Portfolio.git
cd Portfolio
npm install
npm start
```
